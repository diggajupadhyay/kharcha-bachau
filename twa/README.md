# Kharcha Bachau — Android (TWA)

The Android app is a **Trusted Web Activity**: a ~2 MB native shell that opens
the PWA fullscreen (no browser bar) and is verified against this domain via
Digital Asset Links. There is no duplicate app code — the web app *is* the app,
so web deploys reach Android users instantly without a Play Store review.

| | |
|---|---|
| Package ID | `com.kharchabachau.app` (permanent once published) |
| Launch URL | `/app` (from the PWA manifest's `start_url`) |
| Version | `twa-manifest.json` → `appVersionName` / `appVersionCode` |
| Tooling | [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) (`npm i -g @bubblewrap/cli`), JDK 17 at `~/.bubblewrap/jdk/`, Android SDK at `~/.bubblewrap/android-sdk/` |

## Files

- `twa-manifest.json` — app config (name, package, signing, versions)
- `android-keystore` — signing key (**gitignored, back this up!** losing it means
  you can never update the app on the Play Store)
- `keystore.properties` — keystore passwords (**gitignored**)
- `build.sh` — rebuilds the AAB + APK, renders the download page and deploys the
  APK to Cloudflare
- `release-page.html` — template for `/release/` (version + size injected on build)
- `release-cf/` — static Worker hosting the APK at
  `kharcha-bachau-release.dcozupadhyay.workers.dev` (Firebase Hosting's free plan
  forbids executable files, so the APK downloads from Cloudflare)
- `app-release-bundle.aab` — upload this to the Play Console
- `app-release-signed.apk` — signed APK for direct install/testing
- `manifest-checksum.txt` — bubblewrap's edit-detection (regenerated by `build.sh`)

## Build & ship a release

```bash
./build.sh                          # build + render /release/ page + deploy APK to Cloudflare
cd .. && npm run deploy:hosting     # ship the web (incl. the /release/ page)
```

Users download from `kharchabachau.web.app/release/` — the page's button pulls the
latest APK from the Cloudflare URL, which always serves the most recent build.

## Publish to the Play Store

1. Create a [Play Console](https://play.google.com/console) account ($25, one time).
2. Create the app with package ID **`com.kharchabachau.app`** (must match exactly).
3. Upload `app-release-bundle.aab` — internal testing first, then production.
4. **Play App Signing:** Google re-signs the app with its own key. Copy the
   **App signing key certificate** SHA-256 from Play Console → Setup → App signing,
   add it as a second entry in `public/.well-known/assetlinks.json`, and redeploy
   (`npm run deploy:hosting`). Until that fingerprint is live, the app opens in a
   Custom Tab with a URL bar instead of fullscreen.
5. Store listing: privacy policy `https://kharchabachau.web.app/privacy`, screenshots, category.

The fingerprint already in `assetlinks.json` matches the local keystore, so the
locally-built APK runs fullscreen on a device right away:

```bash
adb install app-release-signed.apk
```
